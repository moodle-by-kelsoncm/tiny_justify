Visão Geral - moodle-tiny_justify
=================================

O **moodle-tiny_justify** é um plugin de extensão para o editor **TinyMCE** no Moodle (versões 4.5 ou superiores) que adiciona o botão de **alinhamento justificado de texto** à barra de ferramentas do editor.

Recursos Principais
-------------------

- **Botão Justify Dedicado**: Permite aplicar alinhamento justificado completo a parágrafos ou seleções de texto.
- **Suporte ao TinyMCE 6**: Arquitetura AMD moderna baseada nos módulos `plugin.js`, `commands.js` e `configuration.js`.
- **Compatível com Moodle 4.5+**: Totalmente integrado às configurações visuais da barra do TinyMCE nativo do Moodle.
