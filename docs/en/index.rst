Overview - moodle-tiny_justify
==============================

**moodle-tiny_justify** is an extension plugin for the **TinyMCE** editor in Moodle (version 4.5 or higher) that adds a dedicated **Justify text alignment** button to the editor toolbar.

Key Features
------------

- **Dedicated Justify Button**: Applies full justified alignment to paragraphs or text selections.
- **TinyMCE 6 Support**: Modern AMD architecture based on `plugin.js`, `commands.js`, and `configuration.js` modules.
- **Compatible with Moodle 4.5+**: Fully integrated with Moodle's native TinyMCE toolbar configurations.
