Installation
============

Requirements
------------

- **Moodle**: 4.5 or higher (native TinyMCE editor).

Installation Procedure
----------------------

1. Access the TinyMCE plugins directory:

   .. code-block:: bash

      cd /path/to/moodle/lib/editor/tiny/plugins

2. Clone the repository naming the folder `justify`:

   .. code-block:: bash

      git clone https://github.com/moodle-by-kelsoncm/tiny_justify.git justify

3. Access **Site administration > Notifications** to complete registration of the plugin in the database.
