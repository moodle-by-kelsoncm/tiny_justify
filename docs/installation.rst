Instalação
==========

Requisitos
----------

- **Moodle**: 4.5 ou superior (editor TinyMCE nativo).

Procedimento de Instalação
--------------------------

1. Acesse o diretório de plugins do TinyMCE:

   .. code-block:: bash

      cd /caminho/do/moodle/lib/editor/tiny/plugins

2. Clone o repositório nomeando a pasta como `justify`:

   .. code-block:: bash

      git clone https://github.com/moodle-by-kelsoncm/tiny_justify.git justify

3. Acesse **Administração do site > Notificações** para concluir o registro do plugin no banco de dados.
