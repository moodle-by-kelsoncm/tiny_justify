# Instalação — moodle-tiny_justify

## Requisitos

- **Moodle**: 4.5 ou superior (editor TinyMCE).

---

## Procedimento de Instalação

1. Acesse o diretório de plugins do TinyMCE:
   ```bash
   cd /caminho/do/moodle/lib/editor/tiny/plugins
   ```
2. Clone o repositório nomeando a pasta como `justify`:
   ```bash
   git clone https://github.com/moodle-by-kelsoncm/moodle-tiny_justify.git justify
   ```
3. Acesse **Administração do site → Notificações** para concluir o registro do plugin.
